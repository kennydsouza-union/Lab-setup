# Kali Linux Setup for Ethical Hacking

My personal Kali Linux lab setup for learning penetration testing and CTFs.

## Environment
- **OS:** Kali Linux
- **Platform:** VirtualBox / VMware / Dual boot (pick one)
- **Network mode:** NAT / Bridged (pick one) i choose NAT

## Tools
| Category | Tools |
|----------|-------|
| Recon | Nmap, subfinder, httpx |
| Web | Burp Suite, ffuf, Nikto |
| Exploitation | Metasploit |
| Forensics | Wireshark, binwalk, exiftool |

## Setup Steps
1. Download Kali from kali.org
2. Install and update: `sudo apt update && sudo apt full-upgrade -y`
3. Install extra tools you need
4. Configure networking and snapshots
